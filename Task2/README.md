## Задание 2 - Токенизация и лемматизация

### Запуск из файла Task2
python main.py 
(--input_dir - путь к папке Task1Results с сохранёнными html-документами)
(--stopwords - путь к текстовому файлу stopwords.txt со стопсловами (из библиотеки nltk) )

### Описание

- tokens.txt - список уникальных токенов
- lemmas.txt - токены, сгруппированные по леммам

Программа читает сохранённые HTML-документы, очищает их от разметки,
выделяет отдельные слова (без чисел, стоп-слов и мусора), а затем группирует токены по леммам
