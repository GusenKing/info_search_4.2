### Как запускать

1. Установить зависимости
   > ```shell
   > pip install -r requirements.txt
   > ```
2. Передать параметры при запуске(пример команды с параметрами)
   >```shell
   >python main.py --start_url "https://ru.wikisource.org/wiki/Категория:Сборники_рассказов" --max_depth 2 --max_pages 125 --output_dir Task1Results
   >```
